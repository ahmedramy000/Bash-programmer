# 🐍 باش مبرمج

منصة مراجعة تفاعلية لمنهج تكنولوجيا المعلومات — دروس، تدريبات، اختبارات شاملة، امتحانات نهائية، شهادات ومراكز، ولوحة تحكم للمعلّم. موقع ثابت (HTML/CSS/JS بدون سيرفر) قابل للتثبيت كتطبيق على أندرويد وiOS وويندوز.

---

## 📁 هيكل المشروع

```
باش-مبرمج/
├── index.html              الصفحة الرئيسية (كل الشاشات جوه ملف واحد)
├── manifest.json           إعدادات تثبيت PWA (الاسم، الأيقونات، الألوان)
├── service-worker.js       يشغّل المنصة أوفلاين + إدارة نسخة الكاش
├── css/
│   └── style.css           كل التنسيقات
├── js/
│   ├── data.js             محتوى المنهج: الوحدات، الدروس، الأسئلة، الامتحانات
│   ├── app.js               منطق التطبيق كله (تنقّل، اختبارات، تخزين، أدمن...)
│   ├── certificates.js      نظام المراكز والشهادات
│   └── glossary.js          قاموس المصطلحات (يُبنى تلقائيًا من الدروس)
└── icons/                   أيقونات التطبيق بمقاسات مختلفة
```

---

## 🚀 كيف تنشر المنصة

1. ارفع فولدر `باش-مبرمج` بالكامل (بكل الفولدرات جواه) على أي استضافة ويب ثابتة (Netlify, Vercel, GitHub Pages, أو أي سيرفر عادي).
2. متلمسش هيكل الفولدرات — لازم `css/` و`js/` و`icons/` يفضلوا بجوار `index.html` بنفس الأسماء دي بالظبط.
3. خلاص، المنصة شغالة. الطلاب يفتحوا الرابط ويقدروا يثبّتوها كتطبيق من المتصفح.

---

## 🔄 إزاي تحدّث المنصة بعد النشر

كل مرة تضيف أو تعدّل أي حاجة (دروس، أسئلة، تصميم، فيتشرز):

1. اطلب التعديل، وهتوصلك الملفات المعدّلة.
2. **قبل ما ترفعها**، لازم يتغيّر رقمين (بيتغيّروا تلقائيًا مع أي تعديل حقيقي):
   - `js/app.js` → `const APP_VERSION = "..."` (مثلاً من `1.2.0` لـ `1.3.0`)
   - `service-worker.js` → `const CACHE_NAME = '...'` (مثلاً من `v4` لـ `v5`)
3. ارفع الملفات الجديدة فوق القديمة على نفس الاستضافة (بنفس الأسماء والفولدرات).
4. كل طالب فاتح المنصة قبل كده هيسمع صوت تنبيه ويشوف رسالة "في تحديث جديد، خد نسخة احتياطية من تقدمك" تلقائيًا أول ما يفتحها تاني.

## ⚙️ أماكن الإعدادات المهمة

| الإعداد | مكانه بالظبط |
|---|---|
| رقم إصدار المنصة (لتفعيل تنبيه التحديث) | `js/app.js` — أول 9 سطور، `APP_VERSION` |
| اسم الكاش (أوفلاين) | `service-worker.js` — `CACHE_NAME` |
| روابط فيديوهات كل درس (يوتيوب/تيك توك/فيسبوك/زووم/Google Meet) | `js/data.js` — حقل `links:{}` قبل `quiz:[` في كل درس (34 مكان، شرح كامل في تعليق أعلى الملف) |
| كلمة سر لوحة تحكم الأدمن | `js/app.js` — `ADMIN_PASSCODE` |
| نسبة النجاح المطلوبة لفتح الوحدة التالية | `js/app.js` — `PASS_THRESHOLD` (حاليًا 70%) |
| نسبة النجاح للامتحانات الشاملة الخمسة | `js/app.js` — داخل `submitExam()` (حاليًا 90%) |
| مراكز/شهادات الطالب وشروطها ونصوص التهنئة | `js/certificates.js` — `CERT_TIERS` |
| عدد أسئلة كل محاولة اختبار وحدة | `js/app.js` — `FINAL_TEST_SIZE` (حاليًا 8) |

## 🎓 محتوى المنهج

- **13 وحدة** دراسية، **34 درسًا** تفاعليًا (هدف، نقاط رئيسية، بطاقات مصطلحات، مثال، تذكّر، اختبر نفسك، تدريبات إضافية).
- **13 اختبار وحدة شامل** (بعد إتمام كل دروس وتدريبات الوحدة) — عشوائي في كل محاولة.
- **5 امتحانات شاملة نهائية** (100 سؤال لكل امتحان) تغطي المنهج كله، بعداد وقت وقفل تلقائي عند انتهائه.
- **18 جائزة** قابلة للفتح (13 جائزة وحدة بلا أخطاء + 5 جوائز امتحانات 90%+).
- **6 مراكز/شهادات** بنصوص تهنئة مختلفة، بناءً على الأداء العام في كل الاختبارات.

## 🖨️ تصدير PDF

- كل درس، وحدة (دروس + بنك أسئلة)، وامتحان قابل للتصدير كملف طباعة/PDF من داخل التطبيق.
- الشهادة قابلة للتحميل PNG أو PDF أو الطباعة المباشرة.
- قاموس المصطلحات قابل للتصدير كملف واحد.
- تقرير الجوائز والشهادة قابل للتصدير PDF (وليس JSON، لصعوبة التعديل عليه).

## 📥 تسليم حل ورقي

الطالب يقدر يطبع أي اختبار وحدة أو امتحان شامل، يحله على ورقة، ويرجع "يسلّمه" من داخل التطبيق بإعادة اختيار نفس إجاباته — بتتحسب درجته رسميًا زي ما لو حلها في الموقع مباشرة (بتفتح جوائز وشهادات عادي). نموذج الإجابة نفسه بيفضل مخفي لحد ما الطالب يسلّم حله.

## 👨‍💼 لوحة تحكم الأدمن

الوصول من: صفحة "تقدّمي" → "🔐 لوحة تحكم الأدمن" (محمية بكلمة سر `ADMIN_PASSCODE` في `js/app.js`).

بتدير بيانات كل الطلاب اللي حفظوا تقدمهم على **نفس الجهاز/المتصفح** (مفيدة لجهاز معمل حاسوب بيستخدمه أكتر من طالب): عرض، تصدير، حذف، أو استيراد نسخة طالب فقد بياناته (لو عندك نسخة منها).

> ⚠️ **ملحوظة مهمة:** المنصة موقع ثابت بدون سيرفر أو قاعدة بيانات مركزية. لوحة الأدمن بتشتغل محليًا بس، ومفيش طريقة تقنية تسترجع بيانات طالب مسح الكاش بالكامل من غير نسخة احتياطية محفوظة مسبقًا (تصدير/استيراد JSON) — وده الضمان الحقيقي الوحيد ضد فقد البيانات.

## 🛠️ التقنيات المستخدمة

HTML5 + CSS3 + JavaScript خام (بدون أي framework) — عشان الموقع يفضل خفيف وسريع ويشتغل على أي استضافة بسيطة من غير أي إعداد سيرفر. المكتبة الخارجية الوحيدة هي **jsPDF** (محمّلة من CDN) لتصدير ملفات PDF، ومحتاجة اتصال إنترنت وقت الاستخدام فقط (مع بديل تلقائي عبر الطباعة لو مش متاحة).
